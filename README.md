# Kaushik Barman | Portfolio & Resume Website

A modern, blueprint-styled technical portfolio and resume web application built for Cloud Virtualization lab assignments and showcase.

## 🚀 Features
- **Blueprint Grid Aesthetic**: Graph-notebook grid layout with monospace typography (Space Mono & Courier Prime).
- **Polaroid Profile Frame**: Polaroid photo card with monochrome styling.
- **Paperclipped Skillset Cards**: Realistic pinned cards with metallic paperclips.
- **Single-File Content Configuration**: All texts, qualifications, skills, and photos are configured in `data.js`.
- **Interactive Edit Mode**: Inline editing, photo uploading, and JSON/data export directly in the browser.
- **GitHub Pages Ready**: Self-contained static site ready for instant free hosting.

## 🛠️ Tech Stack
- HTML5
- Vanilla CSS3
- JavaScript (ES6)

## 📁 Project Structure
- `index.html`: Main semantic structure and page layout.
- `style.css`: Blueprint design system and responsive styles.
- `data.js`: Master configuration file to easily edit profile content.
- `script.js`: Interactive engine and edit mode controls.
- `assets/`: Images and profile photos.
